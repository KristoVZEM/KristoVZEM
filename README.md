## Projects

### [Mado](https://github.com/KristoVZEM/mado)

A Windows desktop client for keeping a personal anime library: local watch history, two-way sync with AniList and playback through libmpv. Built with Tauri 2, Svelte 5 and Rust.

- Network access limited to a closed list of hosts and a strict CSP.
- Credentials kept in the Windows Credential Manager, never in files or logs.
- Over 700 automated tests across TypeScript, Svelte components and Rust, run by CI on GitHub Actions.
